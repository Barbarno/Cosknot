# tablero kanban

Tablero enlazado a este repositorio: **GitHub Projects**, con cuatro columnas.

```
┌──────────┬──────────┬──────────┬──────────┐
│ TO DO    │ DOING    │ DONE     │ APPROVED │
└──────────┴──────────┴──────────┴──────────┘
```

Tres reglas del tablero, y las tres se ven en la exposición:

1. **Todas las tareas están escritas.** No hay trabajo que viva solo en la cabeza de
   alguien: si no está en el tablero, no existe.
2. **Las tareas no se borran.** Lo que ya no aplica se queda en *Done* con el motivo
   escrito, para que se vea el trabajo y no solo el resultado.
3. **Cada tarea tiene una persona.** Ninguno de los tres se queda sin tarjetas.

## cómo se lee en pantalla

Se abre el tablero y se señalan dos cosas: **cuatro columnas** y **avatares en todas las
tarjetas**. Es el criterio que pide el enunciado y se ve de un vistazo.
