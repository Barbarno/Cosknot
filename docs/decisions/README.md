# decisiones

Una nota por cada decisión importante de arquitectura o de forma de trabajar.

Uso esta estructura:

```md
# título de la decisión

fecha: aaaa-mm-dd
estado: aceptada

## decisión

qué se ha elegido

## por qué

las razones principales

## alternativas

qué se descartó y por qué

## cuándo revisar

qué haría falta para cambiar de idea
```
